# Hospital Management System

## Project Description

The Hospital Management System is a Python-based application designed to manage hospital operations efficiently. The system uses SQLite as a database and provides functionality for managing patients, doctors, appointments, billing, prescriptions, and medical reports.

## Features

- User registration and login authentication
- Password hashing for user security
- Patient registration and management
- Search patient records
- Update patient information
- Delete patient records
- Doctor registration and management
- Appointment booking
- Billing management
- Prescription management
- Patient medical history
- PDF patient report generation
- Hospital dashboard and analytics
- Database backup functionality

## Technologies Used

- Python
- SQLite Database
- ReportLab (PDF generation)
- Matplotlib (Charts and analytics)
- Git Version Control

## Project Structure

| File | Description |
